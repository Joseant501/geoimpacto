# xilon-docs-nube
Repositorio de texto para sesiones en la nube de Claude (crédito de 100 US$ que caduca el 5 de noviembre, 8:59 CET).

## Cómo usarlo (lo haces tú, 10 minutos)
1. En GitHub: crea un repositorio **PRIVADO** (por ejemplo `xilon-docs-nube`).
2. Sube el contenido de esta carpeta (GitHub Desktop: "Add local repository" → publicar privado; o en la web, "Upload files"). Contiene solo texto: guiones, contexto y tareas. **Sin claves.**
3. Abre una sesión de Claude Code en la nube (claude.ai/code) sobre ese repositorio y pega: *"Lee TAREAS_NUBE.md y haz la TAREA 1. Guarda el resultado en SALIDAS y haz commit."*
4. Repite con las TAREAS 2-5 (una sesión por tarea; pueden ir en paralelo). Orden recomendado: 1, 2, 3, 4, 5.
5. El lunes: descarga `SALIDAS\` del repositorio y cópialo a `G:\YOUTUBE CHANNELS\XILON's EARTH DOCS\CLAUDE\` para tenerlo con el resto.

## Qué no hacer
- No subir `API KEY.txt` ni credenciales de ningún tipo.
- No pedir a la nube que genere vídeo/imagen ni que toque tus cuentas: solo texto.
